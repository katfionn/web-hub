核心心智模型

01

一切皆插件

模型、工具、Skills、会话、沙箱、存储、循环、调度、UI 本身——所有 Agent 能力都由插件组合而成，可自由替换与灵活重组。

02

Cordis 内核

插件运行时由 Cordis 提供：服务注册/注入、事件追加与派发、生命周期钩子，是 Harness 一切机制的底座。

03

Session 四事件

会话事件驱动：四个核心事件 + scope 过滤 + 追加后广播，flush ≠ 持久化，落盘归插件。

04

Agent Loop 主循环

turn/step 双粒度：入口 → 加载 → 日志/存储 → 输入 → prompt + 工具 → agent-loop → LLM → END，END 是状态值而非独立步骤。

05

tools 三层拦截

tools/pre-execute / tools/execute / tools/post-execute，三者都是 @mode waterfall：允许/拒绝/询问 → 派发 → accept/replace/enrich/block。

06

LLM 适配层

LlmAdapter 抽象类 + LlmRuntime.stream 必过 llm/stream waterfall + PreparedLlmCall 深冻结——换模型不改源码的机制。

07

驾驭工程

Harness 的核心价值 = 让 AI 工程化：把 Prompt / Tool / Skill / 沙箱 / 记忆 / 中间件编排成稳定可复现的"工程"。

08

Sandbox 五组件

SandboxSync → OpenSandboxBackend → SandboxBackendProxy（稳定句柄 + 热替换）→ SandboxManager（生命周期）→ SandboxHealthMiddleware（健康钩子）。

09

Skills 自我进化

执行与存储分离（沙箱随时回收，StoreBackend 持久化）；母 Skill skill-management 管全生命周期；渐进式披露节省 token 预算。

10

Context-Engineering 四流程

Input / Compression / Isolation / Long-term Memory；三层压缩：85% 阈值自动摘要 + 手动 compact + 子 Agent 隔离。

11

Multi-Agent + AsyncSubAgent

子 Agent 委派抽取 5 项 + yaml 弹性加载；异步子代理经 Agent Protocol Server 管理，立即返回 task_id，前端 5 秒轮询。

12

中间件管线

9 个中间件形成"健康守护→上下文注入→技能同步→摘要压缩→记忆更新→熔断保护→调用限制"完整生命周期管线，#1 与 #7 协作形成双重保险。

上手路径建议

1. 先跑起来

按 P01 装 Node + npx @deepseek-ai/dsh web，把 Harness 开起来玩 30 分钟，四种预设都点一遍。

2. 读源码入口

从 apps/cli/src/bin.ts 进入，按 P03 的插件树三层覆盖路线走通。

3. 精读主循环

把 P08 主循环 + P06 Agent-Loop + P07 模型适配三讲连着看，理解 turn/step 与 waterfall 事件。

4. 写一个插件

照 P10 四件套模板 + MCP 三件套配置，动手写一个 200 行的玩具插件。

5. 跟 ERP 项目

把 P14-P20 的项目目录、Planning、文件后端、Multi-Agent 跑一遍，理解驾驭工程。

6. 深入六大能力

挑 Sandbox、Skills、Context-Engineering、中间件矩阵四个最硬的深挖，做对照实验。

7. 异步补齐

P33-P35 的 AsyncSubAgent 是生产部署必备，跑通 thread/run/state 协议。
